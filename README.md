## Selected Work

### GuptChat
*Privacy-first real-time chat, built to leave nothing behind.*

A MERN + Socket.IO chat application with no accounts, no databases, and no message history. Rooms are joined with a shared passcode, messages are encrypted client-side before they ever reach the server, and a conversation disappears the moment everyone leaves.

`React` · `Vite` · `Node.js` · `Express` · `Socket.IO` · `Web Crypto API`

[Repository →](https://github.com/siddhartha0812/guptchat) · [Live App →](https://guptchat-brown.vercel.app)

---

### Smart Grocery List
*A clean, glassmorphic grocery tracker for everyday use.*

A browser-based grocery tracker with quantity and price calculation, built entirely with vanilla web technologies and backed by local storage — no backend required.

`HTML` · `CSS` · `JavaScript`

[Repository →](https://github.com/siddhartha0812/Smart-Grocery-List)

---

### Rock, Paper, Scissors
*A small game that listens as well as it reads.*

A Python implementation of the classic game that accepts both spoken and typed input.

`Python`

[Repository →](https://github.com/siddhartha0812/Rock-Paper-and-Scissor-)
